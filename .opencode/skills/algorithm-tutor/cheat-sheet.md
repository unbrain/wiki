# 算法套路小抄（Cheat Sheet）

讲解每道题时，从本文件中挑出对应套路的速查卡附给用户（模板骨架 + 触发词 + 易错点），并把"真实场景"作为记忆锚点。所有模板均为 JavaScript（ES6+）。

## 矩阵模拟（边界收缩）

- **触发词**：螺旋遍历 / 绕圈访问矩阵、按螺旋序输出、转圈打印
- **判断口诀**：从外向内绕圈 → 维护 `top/right/bottom/left` 四边界，撞墙收缩 + 换方向；"剥洋葱"
- **模板骨架**：
  ```js
  const DIRS = { right: [1,0], down: [0,1], left: [-1,0], up: [0,-1] };
  while (res.length < rows * cols) {
    res.push(matrix[y][x]);
    if (dir === 'right' && x === right) { dir = 'down'; top++; }        // 撞墙→收缩身后边界→换方向
    else if (dir === 'down' && y === bottom) { dir = 'left'; right--; }
    else if (dir === 'left' && x === left) { dir = 'up'; bottom--; }
    else if (dir === 'up' && y === top) { dir = 'right'; left++; }
    x += DIRS[dir][0]; y += DIRS[dir][1];
  }
  ```
- **复杂度**：时间 O(m×n) / 空间 O(1)（不计输出）
- **易错点**：转向用 `else if` 防级联换向；dy 向上 -1 向下 +1；以 `res.length < m*n` 为终止条件可免去 `top<=bottom` 守卫；空矩阵提前返回；边界变量与方向名不要重名（如 up/up）
- **真实场景**：打印机螺旋铺墨、无人机螺旋巡飞、图像螺旋采样

## 滑动窗口

- **触发词**：子数组 / 子串 / 连续 + 最长最短 / 恰好满足某条件
- **判断口诀**：连续一段 + 可伸缩区间 → 滑动窗口；窗口"不满足条件才收缩"，只进不退
- **模板骨架**（可变窗口，求最长）：
  ```js
  let l = 0, ans = 0;
  const win = new Map();
  for (let r = 0; r < n; r++) {
    win.set(s[r], (win.get(s[r]) ?? 0) + 1);
    while (窗口不满足条件) {          // 收缩左边界
      win.set(s[l], win.get(s[l]) - 1);
      l++;
    }
    ans = Math.max(ans, r - l + 1);   // 收缩后更新
  }
  ```
- **复杂度**：时间 O(n) / 空间 O(1) 或 O(k)
- **易错点**：收缩用 while 不用 if；先更新窗口再收缩；固定窗口先填满 k 再逐格滑动
- **真实场景**：TCP 拥塞窗口限流、视频网站码率自适应、监控面板滚动统计

## 双指针（对撞）

- **触发词**：有序数组、两数之和、去重、回文判断、反转
- **判断口诀**：左右夹逼，单调移动；通常要求数组有序
- **模板骨架**：
  ```js
  let l = 0, r = n - 1;
  while (l < r) {
    const sum = nums[l] + nums[r];
    if (sum === target) { /* 命中 */ }
    sum < target ? l++ : r--;
  }
  ```
- **复杂度**：时间 O(n) / 空间 O(1)
- **易错点**：排序前提不能丢；三数之和要先去重再移动
- **真实场景**：合并两个有序数组、给数组原地去重

## 二分查找

- **触发词**：有序 / 单调、求最大中的最小或最小中的最大、"O(log n)" 暗示
- **判断口诀**：答案可猜 + 判断单调 → 对答案二分；找"第一个满足/最后一个不满足"
- **模板骨架**（闭区间）：
  ```js
  let lo = 0, hi = n - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (check(mid)) hi = mid - 1;   // 收缩方向由 check 定义
    else lo = mid + 1;
  }
  ```
- **复杂度**：时间 O(log n) / 空间 O(1)
- **易错点**：`lo <= hi` 与 `lo < hi` 的区间语义保持一致；`(lo+hi)>>1` 避免溢出；check 必须单调
- **真实场景**：git bisect 定位坏提交、查词典、B+ 树索引查找

## 单调栈

- **触发词**：下一个更大 / 更小元素、每日温度、柱状图最大矩形、接雨水
- **判断口诀**：找"左边/右边第一个比它大（小）"→ 单调栈；答案在弹出时结算
- **模板骨架**（下一个更大元素，栈内放下标）：
  ```js
  const st = [], ans = new Array(n).fill(-1);
  for (let i = 0; i < n; i++) {
    while (st.length && nums[st[st.length - 1]] < nums[i]) {
      ans[st.pop()] = i - st[st.length - 1]; // 结算
    }
    st.push(i);
  }
  ```
- **复杂度**：时间 O(n) / 空间 O(n)
- **易错点**：栈内存下标而非值；相等元素用 `<` 还是 `<=` 决定是否严格；结算时机在弹出时
- **真实场景**：股票 K 线找高低点、城市天际线轮廓

## 堆 / Top K

- **触发词**：第 K 大 / 小、前 K 个高频、合并 K 个有序链表、动态取最值
- **判断口诀**：只需要"最有价值的那几个"→ 小顶堆维护 TopK 大（或反之）；K 与 n 同阶时直接排序
- **模板要点**：JS 无内置堆，手写或用数组排序兜底；堆化 O(n)、插入/删除 O(log n)
- **复杂度**：TopK 用堆 O(n log k) / O(k)；排序法 O(n log n)
- **易错点**：大小顶堆方向反了；比较函数在 Node 内存下标；K=0 / K>n 边界
- **真实场景**：微博热搜榜、操作系统进程调度、外卖骑手派单优先级

## LRU 缓存

- **触发词**：LRU、缓存淘汰、get/put 都要 O(1)
- **判断口诀**：哈希表找位置 + 双向链表记顺序 → 命中移到头部、满则淘汰尾部
- **模板要点**：
  ```js
  class Node { constructor(k, v) { this.k = k; this.v = v; this.prev = null; this.next = null; } }
  class LRUCache {
    constructor(capacity) { this.cap = capacity; this.map = new Map(); /* + 哨兵头尾 */ }
    get(key)    { /* 命中 → 移到头部，返回 v */ }
    put(k, v)   { /* 存在则更新并移头部；不存在则插入头部，超容量删尾部 */ }
  }
  ```
- **复杂度**：get / put 均 O(1) / O(capacity)
- **易错点**：哨兵节点简化边界；删除节点要断开前后指针；Map 顺序与实际双向链表一致
- **真实场景**：浏览器后退缓存、Redis 内存淘汰、CPU 缓存行替换

## Trie 前缀树

- **触发词**：前缀匹配、单词搜索、自动补全、多个单词的共享前缀
- **判断口诀**：字符串集合 + 前缀查询 → 字典树，空间换时间
- **模板骨架**：
  ```js
  class Trie {
    constructor() { this.children = {}; this.isEnd = false; }
    insert(w) { let p = this; for (const c of w) p = p.children[c] ??= new Trie(); p.isEnd = true; }
    search(w) { const p = this.find(w); return !!p && p.isEnd; }
    startsWith(w) { return !!this.find(w); }
  }
  ```
- **复杂度**：插入 / 查询 O(词长) / O(总字符数)
- **易错点**：`isEnd` 标记单词结尾；`??=` 建子节点；区分 search 与 startsWith
- **真实场景**：输入法联想、搜索引擎自动补全、敏感词过滤

## 并查集

- **触发词**：连通性 / 连通分量、朋友圈、岛屿个数（合并视角）、动态连接
- **判断口诀**：点之间的关系不断"合并 + 查询连通"→ 并查集
- **模板骨架**：
  ```js
  class DSU {
    constructor(n) { this.p = Array.from({ length: n }, (_, i) => i); this.rank = new Array(n).fill(0); }
    find(x) { return this.p[x] === x ? x : (this.p[x] = this.find(this.p[x])); } // 路径压缩
    union(a, b) { /* 按秩合并 */ }
  }
  ```
- **复杂度**：近似 O(1)（反阿克曼函数）/ O(n)
- **易错点**：必须路径压缩；union 前先 find；统计连通块时数根
- **真实场景**：微信好友的群连通、电路连通性检测、Kruskal 最小生成树

## BFS / DFS（图与搜索）

- **触发词**：迷宫 / 网格最短路径（无权图）、层序遍历、连通块、拓扑排序、全排列与组合（回溯）
- **判断口诀**：求最短步数 → BFS；求所有方案 / 可达性 → DFS；网格题先想方向数组
- **模板要点**：BFS 用队列，入队时立即标记 visited（防重复入队）；DFS 递归 + 回溯撤销状态
- **复杂度**：时间 O(V+E) / O(V)
- **易错点**：visited 出队才标记会超时/爆内存；回溯要撤销；网格越界检查先做
- **真实场景**：地图导航、网络爬虫层级抓取、六度人脉推荐

## 动态规划

- **触发词**：最大 / 最小 / 方案数 + 子序列子数组、选或不选、重叠子问题
- **判断口诀**：暴力递归有重复子问题 → DP；写清 dp 含义再动笔
- **模板五步**：① 定义状态 → ② 转移方程 → ③ 初始化 → ④ 遍历方向（依赖谁就先算谁）→ ⑤ 滚动数组压缩空间
- **常见模型**：背包（选/不选）、LIS / LCS、区间 DP、打家劫舍类、编辑距离
- **复杂度**：常见 O(n²) / O(n)
- **易错点**：dp 含义写清（是值还是方案数）；遍历方向错了就引用旧值；初始化边界（0 与空串）
- **真实场景**：拼写纠错（编辑距离）、基因序列比对、广告位资源分配（背包）

## 贪心

- **触发词**：局部最优、区间调度（会议室）、找零、跳跃游戏
- **判断口诀**：先排序（按终点/起点），每次取当前最优且"反证不被替换"→ 贪心；只满足局部最优不一定对
- **复杂度**：排序 O(n log n) + 线性扫描 O(n)
- **易错点**：别把需要 DP 的题硬套贪心（如背包 0/1）；区间题先想清楚按起点还是终点排
- **真实场景**：Huffman 压缩编码、会议厅排期、Dijkstra 最短路

## 回溯

- **触发词**：全排列、组合、子集、N 皇后、数独、"所有可能方案"
- **判断口诀**：求全部方案 → 递归 + 选择 + 撤销；去重先排序再相邻剪枝
- **模板骨架**：
  ```js
  function backtrack(path, start) {
    if (path.length === k) { ans.push([...path]); return; }
    for (let i = start; i < n; i++) {
      path.push(nums[i]);
      backtrack(path, i + 1);   // 组合：i+1；排列：全量 + used
      path.pop();               // 撤销
    }
  }
  ```
- **复杂度**：O(方案数 × 方案长度)
- **易错点**：撤销漏掉就错；重复元素先排序 + `i > start && nums[i] === nums[i-1]` 剪枝
- **真实场景**：数独求解、八皇后、密码暴力破解、旅行商枚举

## 位运算

- **触发词**：只出现一次、成对抵消、2 的幂、子集枚举、两数交换
- **判断口诀**：异或消重复（a^a=0）；`x & (x-1)` 消最右 1；`1 << i` 做标记
- **常用操作**：
  ```js
  x ^ y;            // 无临时变量交换
  x & (x - 1);      // 去掉最右侧的 1
  x & -x;           // 取最右侧的 1
  (x >> i) & 1;     // 取第 i 位
  ```
- **复杂度**：O(1) ~ O(n)
- **易错点**：JS 位运算 32 位有符号，大数场景小心；优先级（位移低于加减）加括号
- **真实场景**：Linux 文件权限位、Bitmap 去重、布隆过滤器

## 快慢指针（链表）

- **触发词**：链表判环、找中点、倒数第 K 个节点
- **判断口诀**：一快一慢，快走两步慢走一步 → 相遇即环；快到头即无环
- **模板要点**：判环后让 slow 回头部再同步走，相遇点即入环节点
- **复杂度**：时间 O(n) / 空间 O(1)
- **易错点**：while 条件 `fast && fast.next`；环入口推导用数学式而不是死记
- **真实场景**：龟兔赛跑、检测死循环引用、DNS 查询环路检测
