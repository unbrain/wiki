## [Andrej Karpathy](https://x.com/karpathy)
> [!info] @karpathy · 405.2w 粉丝 · 年内 70 条原创 · 覆盖 2025-09-05 ~ 2026-07-21
**画像**：兼具教育家与研究者身份的理性技术派，爱晒实测与开源实验（风格：理性、热忱）

### 年度主题
- **AI重塑编程** — 他判断 coding agents 在2025年12月前后发生质变，自己从八成手写代码转为八成 agent 编程，并坦言“从没像现在这样感觉落后”。他还关注 Tab 补全与 Agent 用量的此消彼长，看好 agent 友好的 CLI 与“高度定制化软件”成为新形态。

- **LLM知识工作新范式** — 他把大量 token 投入用 LLM 构建个人知识库与个人 wiki，认为显式、可审计的记忆工件比“越用越懂你”的黑箱个性化更可靠。他还做了 llm-council 多模型评审应用，推崇语音 ramble、把回复结构化为 HTML 等新交互，并畅想 SETI@home 式异步大规模协作的 autoresearch。
- **自动驾驶与AI落地** — 他提走 HW4 版 Model X 后赞叹 FSD 驾驶品质大幅提升，年底庆祝 FSD V14.2 完成2732英里零接管的首次全自动驾驶横穿美国。他称自动驾驶将是几十年来首个明显改造户外物理空间与生活方式的技术。

## [Andrew Ng](https://x.com/AndrewYNg)
> [!info] @AndrewYNg · 184.6w 粉丝 · 年内 89 条原创 · 覆盖 2025-09-04 ~ 2026-08-28
