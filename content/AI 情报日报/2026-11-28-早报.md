# 🐦 AI 情报日报（2026-11-28）

## 🔥 今日热点新知

- **[Anthropic 推出 Skills over MCP 公测与 Tasks、Elicitation 更新]** — Anthropic 宣布 Skills over MCP 在 Claude 与 Claude Code 进入公开测试，允许 MCP 服务器在工具之外发布技能并按需加载，从而降低上下文占用，同时配套推出 Tasks、Elicitation 等更新。该机制直接针对多工具接入场景下的上下文膨胀问题，让技能分发与 MCP 协议进一步绑定。([来源](https://aihot.news/items/kjd2qp2iuk9zxdfqj5qk2a8f9))
- **[Claude 推出 Install as app，Artifacts 可安装为独立桌面应用]** — Anthropic 在 Mac 和 Windows 版 Claude 中以 beta 形式上线 Install as app，支持将 artifacts 创建、运行并分享为拥有独立图标和窗口的桌面应用，且底层 artifact 更新时应用会自动同步；同期月度回顾（Reflect）在 Web、桌面端和移动端对 Free、Pro、Max、Ultra 套餐转正，并开启连接器文件传输 beta。这让 Claude 生成的轻量工具从对话窗口延伸到系统桌面常驻入口。([来源](https://aihot.news/items/zcpto4b7qb8sr6v6n223kd2sx))
- **[上海 AI 实验室 InternLM 发布开源全双工音视频模型 Sage-Interaction]** — 上海人工智能实验室 InternLM 团队基于 MiniCPM-o 4.5 打造并开源了全双工语音视频模型 Sage-Interaction，支持边说边听，并在不打断对话的前提下将复杂任务交给后端模型处理。OpenBMB 转发点评称其是迈向更自然 AI 交互的一步，展示了端侧实时交互与后端重推理协同的架构思路。([来源](https://aihot.news/items/l9md8ugx8e2zlm5g1tuqthmaw))
- **[Mantic 与 Thinking Machines 训练可扩展预测智能体，单次成本降 15 倍]** — Mantic 与 Thinking Machines 在 Tinker 上对 Inkling 2 Small 进行后训练，构建出端到端完成研究与预测的预测智能体，其准确度接近 Fable 5.2 (medium)，而单次预测成本降低 15 倍。该结果验证了小模型经针对性后训练后，在垂直研究与预测任务上替代中等规模前沿模型的性价比空间。([来源](https://aihot.news/items/yh9lmlhqwoc77d1ii1mvr5d6x))
- **[Convex Agent Skill 被曝静默上传用户应用构想至远程服务器]** — GitHub Issue（`convex/convex-backend-skill#64`）披露 Convex 的技能包会在未告知用户的情况下将用户的应用构想发送至远程服务器，在 Hacker News 收获 221 分与 70 条评论。在各家加速推广 Agent Skills 与 MCP 生态的节点上，这一事件直接暴露了第三方技能包的隐私与供应链审计盲区。([来源](https://github.com/convex/convex-backend-skill/issues/64))
- **[美国 BIS 租赁算力新规生效，门槛约 760 块 H100 等效算力]** — ChinaTalk 分析美国 BIS 于 11 月 16 日发布、11 月 19 日生效的租赁算力临时最终规则：向境外数据中心供应芯片需申领许可，门槛约为 760 块 H100 等效算力，覆盖 Hopper 与 Blackwell 级芯片并关闭 Foundry Due-Diligence 漏洞。作者基于自建模型测算该规则或为美国换取约六个月算力领先，并梳理了柔佛数据中心与执法风险等变量。([来源](https://aihot.news/items/yz5va6l60tfkmdampmsiz0jq2))

# 📐 深度分析与探讨

## 交叉印证：Agent 生态的“能力扩张”与“信任赤字”

把今天的 FOMO 情报、HN 榜单和 X 推文放在一起看，能看到一条清晰的温差线。官方与产品侧正在加速把 Agent 能力往外推：Anthropic 一边在 Claude 与 Claude Code 公测 `Skills over MCP`，让 MCP 服务器直接发布可按需加载的技能；另一边在 Mac 和 Windows 端推出 `Install as app`，把 artifacts 封装成带独立图标和窗口、可自动同步更新的桌面应用。

但开发者社区在 HN 和 X 上泼出的冷水，恰恰打在“客户端与技能黑盒”上。HN 上 `Convex skills send the user's app idea to a remote server without telling them` 拿到 221 分和 70 条评论，直指第三方 Skill 在无提示情况下外传用户输入；X 上 `@dotey` 转发 Unicorn 的反馈也指出，部分用户觉得 `neon` 幻觉大并非模型本身不行，而是“反重力桌面端”（不含 CLI）的上下文处理出了问题。

两相对照，社区的担忧比官方发布更贴近一线工程痛点：当技能通过 MCP 动态注入、上下文由桌面客户端自动拼接时，开发者既看不清提示词和上下文被改写了什么，也难以第一时间察觉第三方 Skill 是否夹带了静默网络请求。能力封装越顺滑，透明度和可审计性就越容易成为短板。

## 趋势判断：从“巨型模型硬扛”转向“小模型专精 + 分层协同”

今天多条看似分散的信号，共同指向同一个结构性变化：AI 应用正在从“所有请求都丢给单一巨型模型”，转向“小模型专精 + 前后端分层 + 按需加载上下文”。

在模型训练与推理侧，Mantic 与 Thinking Machines 在 `Tinker` 上对 `Inkling 2 Small` 做后训练，让预测智能体在准确度接近 `Fable 5.2 (medium)` 的同时把单次预测成本压低 15 倍；`@swyx` 转发的 Cloudflare `@michellechen` 演讲也明确提出 `Your LLM might be overkill`，讨论从服务巨型模型转向训练小型决策模型（small decision models）。

在交互与协议侧，上海 AI 实验室 InternLM 基于 `MiniCPM-o 4.5` 推出的开源全双工模型 `Sage-Interaction`，采用“边说边听、不打断对话、把复杂任务交给后端模型”的分层架构；Anthropic 的 `Skills over MCP` 则通过按需加载技能来削减上下文占用。这些做法的共同逻辑是把高频、低延迟或固定模式的环节下沉给小模型或按需模块，把昂贵的前沿模型和上下文窗口留给真正需要复杂推理的步骤。

## 机会与风险：开发者接下来该做什么

对一线开发者而言，短期最值得投入的方向是“成本分层”和“轻量桌面化”。如果业务里有高频分类、路由或研究预测任务，可以参考 `Inkling 2 Small` 在 `Tinker` 上后训练降本 15 倍以及 Cloudflare 小型决策模型的思路，测试用小模型后训练替代中等规模通用模型；内部高频小工具则可以试用 Claude 的 `Install as app` 和 `Skills over MCP`，验证按需加载技能对长会话上下文占用的改善效果。

需要重点规避的风险则是“盲装第三方 Skill”和“忽视桌面端上下文黑盒”。在引入任何社区 Agent Skill 或 MCP 技能包前，应先检查其脚本与网络请求行为，避免重演 `convex-backend-skill#64` 的数据外泄问题；同时在评估新模型（如 `neon`）效果时，优先用 CLI 或可控 API 跑对照，避免把桌面客户端的上下文拼接问题误判为模型能力缺陷。
