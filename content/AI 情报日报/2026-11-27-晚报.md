# 🐦 AI 情报日报（2026-11-27）
## 🔥 今日热点新知
- **OpenAI 发布预印本：GPT-6 展现内在蛋白质设计能力** — OpenAI 称 GPT-6 系列模型仅凭推理和通用编码工具即可设计新蛋白的结构与序列，无需调用专用生物学模型。在与 Onava 的实验室测试中，基于 GPT-6.2 设计的 minibinder 在 5 个靶点上均出现结合证据，322 个中 35 个（10.9%）呈结合阳性，重设计的抗体片段 66% 保留结合。([来源](https://aihot.news/items/yg04c9d5qnwzitqstg19c6ow2))
- **Anthropic 复盘 Messages API 从 Python 迁移至 Rust** — 面对 2024 年初至 2026 年秋约 1800 倍的流量增长，Anthropic 将生产系统本身作为校验器完成迁移，期间未停服也未冻结功能开发。迁移后每请求 CPU 消耗降低约 70%，首 token 中位时间缩短约 20%。([来源](https://aihot.news/items/h1ja45355xx1xf9rqf89cv1if))
- **Amazon 威胁情报：黑客用 Cairn 驱动 AI 智能体 11 分钟利用 0-day** — 黑客在开源 AI 渗透测试框架 Cairn 上运行智能体，仅凭一句「获取 shell 权限」指令，便自主发现并利用开源医学影像 AI 应用中未修补的路径遍历 0-day。从映射 API 到任意写文件仅用约 11 分钟，随后写入 Python 反向 shell payload 并以 root 权限获得控制。([来源](https://aihot.news/items/ygbhvp086wl672gfxuhfgl23x))
- **Dragos 调查称 MiniMax 打开用户提示词中的私有链接** — 美国安全公司 Dragos 披露，即便用户明确请求不存储数据，MiniMax 仍收集并打开了用户提示词中包含的私有链接，暴露出推理链路中的隐私与数据边界风险。([来源](https://aihot.news/items/v5fxjqr2vapkk9vn1j9a8ke96))
- **腾讯开源 MoE 模型 Hy4 Flash 上线 Fireworks serverless** — Hy4 Flash 总参数约 220B、每 token 激活约 12B，原生支持 1M token 上下文（Fireworks 上线版本为 512K）及文本、图像输入，面向文档处理、研究、办公与 Agent 工作流。([来源](https://aihot.news/items/dvu6olan4q58k1evvnp8t60t2))
- **Antigravity 技巧：在 GEMINI.md 加一句话让模型边干活边汇报** — 针对模型长时间闷头执行不输出中间状态的问题，卡兹克分享在 `GEMINI.md` 中加入一句约束，要求模型在动手前、有发现、换方向、卡住或连干四五步时主动汇报，以获得类似 Claude 或 Codex 的实时进度反馈。([来源](https://aihot.news/items/tiqf353lek6sib8ktn8uvc6nc))

## 趋势判断：通用推理外溢与“低激活 MoE + 百万上下文”并行

今天的多条热点共同指向两个结构性变化。第一，通用推理与编码工具正在跨界替代部分专用模型与人工安全流程。OpenAI 预印本强调 GPT-6 无需调用专用生物学模型即可完成蛋白结构与序列设计；另一端，Amazon 报告显示开源框架 Cairn 仅凭一句「获取 shell 权限」就能在约 11 分钟内完成 API 映射到 root 权限控制。通用智能体能力的外溢，同时压低了科研探索与自动化攻击的门槛。

第二，模型供给侧的竞争正收敛到“大总参、低激活 MoE + 百万级上下文”的性价比区间，并倒逼底层 API 基础设施重构。腾讯 Hy4 Flash（总参约 220B、激活约 12B、原生 1M 上下文）上线 Fireworks serverless，inclusionAI 的 Ling 3.2 Flash（1.0M 上下文、输入 $0.3000/M、输出 $0.9000/M）上线 OpenRouter，二者均瞄准长文档、研究与 Agent 工作流。当长上下文与高并发 Agent 调用成为常态，Anthropic 将 Messages API 从 Python 迁至 Rust 以应对 1800 倍流量增长，说明推理网关与服务层的系统工程效率已成为头部厂商的硬约束。

- **GPT-6.2 蛋白设计的对照基线与工具分工**：素材仅给出 Onava 实验室测试中 5 个靶点、322 个 minibinder 中 35 个（10.9%）阳性及抗体片段 66% 保留结合的数据，但未说明这 5 个靶点的难度分布、与专用蛋白设计模型在同等预算下的对比基线，以及通用编码工具具体承担了哪些计算步骤。

## 机会与风险：开发者的工程优先级与安全红线

对开发者而言，百万上下文与低激活 MoE 模型的普及降低了长链路 Agent 的试错成本，例如 Ling 3.2 Flash 在 OpenRouter 上输入 $0.3000/M、输出 $0.9000/M 的定价，以及 Fireworks 上托管的 Hy4 Flash（512K 上下文），都适合用于文档处理与研究型工作流。在工程实践上，Anthropic 用生产系统本身作为校验器完成 Python 到 Rust 迁移的思路，以及在 `GEMINI.md` 中通过单句约束让模型在动手前、卡住或连干四五步时汇报进度的做法，均可直接借鉴。

风险则集中在“模型与服务端对外部资源的访问权限”。Cairn 框架 11 分钟利用开源医学影像 AI 应用路径遍历 0-day 的案例表明，暴露在公网的 AI 应用与未修补组件正面临自动化渗透测试；而 Dragos 对 MiniMax 的调查提醒开发者，向第三方模型 API 发送包含内网地址、签名 URL 或私有链接的提示词前，不能仅依赖“不存储数据”的声明，必须在网络层与脱敏层做硬隔离。
