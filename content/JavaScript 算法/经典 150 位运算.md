[190. 颠倒二进制位](https://leetcode.cn/problems/reverse-bits/)

```javascript
var reverseBits = function(n) {
  let res = 0
  for (let i = 0; i < 32; i++) {
    res = (res << 1) | (n & 1)
    n >>>= 1
  }
  return res >>> 0
}
```
