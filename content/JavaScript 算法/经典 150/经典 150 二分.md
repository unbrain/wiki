[35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/)

```javascript
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number}
 */
var searchInsert = function(nums, target) {
    let left = 0;
    let right = nums.length - 1; // 采用闭区间 [left, right]

    while (left <= right) {
        // 防止 (left + right) 大数溢出，等价于 Math.floor((left + right) / 2)
        const mid = left + Math.floor((right - left) / 2);

        if (nums[mid] === target) {
            return mid; // 命中目标直接返回
        } else if (nums[mid] < target) {
            left = mid + 1; // target 在右半边，缩小至 [mid + 1, right]
        } else {
            right = mid - 1; // target 在左半边，缩小至 [left, mid - 1]
        }
    }

    // 循环结束时必定有 left = right + 1
    // 此时 nums[0 ... left-1] < target，且 nums[left ... n-1] > target
    // 因此 target 插入的位置恰好就是 left
    return left;
};
```

- **时间复杂度**：$O(\log n)$，每次比较排除一半搜索区间。
- **空间复杂度**：$O(1)$，仅使用了常数个指针变量。

**关键套路与不变式**：
1. **闭区间自洽三要素**：
   - 初始化：`right = nums.length - 1`
   - 循环条件：`left <= right`（区间不为空）
   - 区间缩小：`left = mid + 1` 或 `right = mid - 1`（排除已知不符合的 `mid`）
2. **为什么返回 `left`**：
   - 循环不变式保证了 `nums[0 ... left-1] < target` 且 `nums[right+1 ... n-1] > target`。
   - 当 `left > right` 退出时，`left` 刚好等于 `right + 1`，它指向第一个大于 `target` 的元素位置，也正是 `target` 应当插入的位置。

[74. 搜索二维矩阵](https://leetcode.cn/problems/search-a-2d-matrix/)

```javascript
/**
 * @param {number[][]} matrix
 * @param {number} target
 * @return {boolean}
 */
var searchMatrix = function(matrix, target) {
    const m = matrix.length;
    const n = matrix[0].length;

    let left = 0;
    let right = m * n - 1; // 将 m * n 的矩阵视作长度为 m * n 的一维有序数组

    while (left <= right) {
        const mid = left + Math.floor((right - left) / 2);

        // 核心映射公式：一维下标转二维坐标
        const row = Math.floor(mid / n);
        const col = mid % n;
        const val = matrix[row][col];

        if (val === target) {
            return true;
        } else if (val < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return false;
};
```

- **时间复杂度**：$O(\log(m \times n))$，在 $m \times n$ 个元素的有序序列中进行标准二分。
- **空间复杂度**：$O(1)$，常数级额外空间。

**关键套路**：
- **二维展平映射**：对于 $m$ 行 $n$ 列的矩阵，一维索引 `index` 对应二维坐标 `[Math.floor(index / n), index % n]`。
- **适用前提**：每行递增且下一行首元素大于上一行末元素，保证矩阵整体严格单调递增。
