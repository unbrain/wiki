## 本地开发

<p align="center">
  <img src="assets/section-dev.svg" width="100%" alt="本地开发：安装依赖、构建与本地预览">
</p>

```bash
pnpm install     # 安装依赖
npx quartz build # 构建到 public/
npx quartz serve # 本地预览 http://localhost:8080
```
